<h1 align="center">ФинТрек</h1>

<p align="center">Личный финансовый трекер для Android на .NET MAUI.</p>

## О приложении

ФинТрек — локальное приложение для учёта личных финансов. Счета, операции, лимиты,
долги, аналитика и импорт банковских уведомлений. Данные хранятся на устройстве
в зашифрованной базе SQLite (SQLCipher).

Основная платформа — Android 5.0+.

## Возможности

- счета и балансы: основной счёт, наличные;
- доходы, расходы, переводы между счетами;
- долги и займы;
- лимиты на неделю, месяц и год с расчётом остатка и дневного лимита;
- рекомендации по категориям для соблюдения бюджета;
- аналитика: категории, динамика, радар, вафля, рейтинг;
- тепловая карта расходов по дням месяца;
- импорт операций из SMS и уведомлений банковских приложений;
- выбор категорий, иконок и цветов;
- экспорт операций в CSV;
- биометрический вход;
- тёмная и светлая тема, акцентный цвет;
- русский интерфейс, белорусские рубли и другие валюты.

## Технологии

- .NET 10, C#;
- .NET MAUI (Android);
- SQLite + SQLCipher;
- Microsoft.Maui.Graphics для диаграмм;
- Plugin.Fingerprint для биометрии.

## Сборка

Требования: .NET 10 SDK, MAUI Android workload, JDK 21, Android SDK.

```powershell
dotnet workload install maui-android
dotnet build FinTracker/FinTracker.csproj -f net10.0-android -c Release
```

APK формируется в `FinTracker/bin/Release/net10.0-android/`.

Для установки на подключённое устройство:

```powershell
dotnet build FinTracker/FinTracker.csproj -f net10.0-android -c Debug -t:Run
```

## Разрешения

- **SMS** — импорт банковских операций из сообщений. Необязательно.
- **Доступ к уведомлениям** — импорт операций из уведомлений банковских приложений
  и Samsung Wallet. Необязательно.
- **Биометрия** — вход по отпечатку. Необязательно.

Все разрешения можно не выдавать: приложение работает в ручном режиме.

## Приватность

Приложение не отправляет финансовые данные на внешние серверы. База данных
хранится локально и зашифрована. Уведомления и SMS обрабатываются на устройстве.
Телеметрия отсутствует.
