Технологии

.NET 10 C# .NET MAUI Android SQLite SQLCipher MAUI Graphics

Сборка

Требования: .NET 10 SDK, MAUI Android workload, JDK 21, Android SDK.

dotnet workload install maui-android dotnet build FinTracker/FinTracker.csproj -f net10.0-android -c Release

APK формируется в FinTracker/bin/Release/net10.0-android/. Для установки на подключённое устройство используется dotnet build -t:Run.

Приватность

Финансовые данные не покидают устройство.

База данных зашифрована. Уведомления и SMS обрабатываются локально. Приложение не использует серверы, аккаунты и телеметрию. Доступ к уведомлениям и SMS необязателен: без них приложение работает в ручном режиме.

Хранение

SQLite + SQLCipher. Локальная база в sandbox приложения.
